# 쉥겐 체류 계산기

아이폰 홈 화면에 설치해 사용하는 간단한 90/180일 체류 계산기입니다. 서버 없이 브라우저 내부에 체류 기록을 저장합니다.

## GitHub Pages 게시
1. GitHub의 `schengen` 저장소를 열고 **Add file → Upload files**를 선택합니다.
2. 이 ZIP을 압축 해제한 뒤 `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`를 **저장소 최상위(root)** 에 업로드하고 Commit합니다. (README.md는 선택)
3. **Settings → Pages → Build and deployment → Deploy from a branch**를 선택하고 **main / (root)** 로 설정한 후 Save합니다.
4. 게시 후 `https://사용자명.github.io/schengen/`으로 Safari에서 접속합니다. (공개 저장소는 누구나 페이지에 접근할 수 있으나 입력 기록은 업로드되지 않습니다.)
5. Safari의 공유 메뉴 → **홈 화면에 추가**를 선택합니다. 최초 온라인 접속 이후 오프라인 사용을 지원합니다.

## 데이터 및 계산 주의사항
- 기록은 설치한 웹 앱의 localStorage에 저장됩니다. 다른 기기나 Safari 탭과 자동 동기화되지 않을 수 있습니다.
- **백업 파일 저장**으로 JSON을 파일 앱에 보관하고 **백업 파일 불러오기**로 복원하세요.
- 입국일과 출국일 모두 체류일로 계산하며, 오늘 기준 직전 180일의 체류일수와 해당 기간 내 90일 초과 여부를 확인합니다.
- '잔여일'은 오늘 기준 단순 잔여일이며, 향후 연속 체류 가능일수는 아닙니다. 비자/체류허가 등 예외는 고려하지 않습니다.
- 출국 예정일을 입력하면 오늘 이후의 날짜는 현재 사용일수에 포함되지 않습니다.
